Um sistema de agentes do Claude Code, mais o Argos, uma ferramenta que lê as respostas em voz alta.

## O que existe

- `agents/`: pasta reservada para as definições dos agentes.
- `argos/`: pasta reservada para o Argos.
- `docs/`: pasta reservada para a documentação.
- `tests/`: teste de privacidade, que impede dados pessoais de entrar no repositório.

## O que vem

- Definições dos agentes.
- O código do Argos.
- Documentação de uso.
